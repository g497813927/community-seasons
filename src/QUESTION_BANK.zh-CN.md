# 铁路题库审阅与编辑

[English](QUESTION_BANK.md) | [简体中文](QUESTION_BANK.zh-CN.md)

编辑 **`lib/game/rail-questions.json`**。此 JSON 是游戏题库的数据源。所有示例均为虚构教学情境，不引用真实用户原文，也不声称复现平台官方处理决定。

每道题包含以下字段：

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定、唯一的标识；修改已有题目时保留。 |
| `topic` | 便于审阅和整理的主题。 |
| `prompt.en`, `prompt.zh` | 英语和简体中文题干。 |
| `options` | 按 JSON 顺序排列，必须恰好有三个选项。 |
| `options[].label.en`, `.zh` | 双语选项文本。 |
| `options[].why.en`, `.zh` | 玩家选择该项后显示的双语解析；错误选项也需提供。 |
| `correctIndex` | **0 为第一项，1 为第二项，2 为第三项。** |
| `source`（可选） | 仅供审阅的来源动态、账号、日期、段落及改编说明，不进入游戏或分享卡片。 |

题库共 47 题：原有 8 题、新增 23 道虚构情境题，以及依据公开治理动态改编的 16 道虚构题。这 16 题的 `source.dateType` 区分发布时间与页面显示的编辑时间。来源账号、真实事件、真实姓名和链接仅保留在审阅 JSON 中；生成的游戏数据只包含改编后的题目和答案。

`correctIndex` **不对应固定的左、中、右轨道**：游戏会为每题打乱选项顺序。每次小车行程仍抽取 3–4 道不重复的题；增加题库只会扩大抽题范围，不会延长单次行程。

会话题组会在重试和补充题目时保留近期出题保护。修改抽题或重新洗牌逻辑时，必须保留这项保护：重试不得丢弃近期出题记录，也不得消耗玩家尚未看到的题目。

答案判定后，可点击**分享这道题**，用当前语言将虚构题干、正确答案及该答案的解析生成学习卡。障碍物观察站也可通过**分享这份提醒**，分享脱敏示例和建议回应。打开铁路学习卡会暂停游戏；关闭后，准备好再按继续。卡片使用 Toy 默认游戏二维码，不包含真实案例来源链接或账号身份。任何内容都不会自动分享或保存。

保持双语含义一致，每题只有一个明确、站得住脚的正确答案，并为每个选项提供针对该项的解析。选项应简短，适合手机屏幕。敏感内容使用 `[insult]` / `[侮辱词]` 等占位符。不要添加真实姓名或未经核实的案例链接。

编辑后，在本项目目录执行：

```sh
npm run questions:sync
npm run questions:validate
npm run build
```

`npm run dev` 和 `npm run build` 会在启动前自动同步 JSON。开发服务器已经运行时，如果修改了 JSON，请运行一次 `npm run questions:sync` 以更新游戏。JSON 格式错误、翻译缺失、ID 重复、选项重复、答案索引无效或文本过长，都会导致校验失败，并报告具体字段位置。校验只检查结构，不判断答案在教学上是否正确；发布前仍需审阅内容。

`lib/game/railway.ts` 内的 `RAIL_QUESTIONS` 区段由脚本生成。请编辑 JSON，不要直接修改该生成区段；铁路的其余逻辑不受题库同步影响。
