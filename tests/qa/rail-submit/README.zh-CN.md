# 铁路答题提前提交回归测试

[English](README.md) | [简体中文](README.zh-CN.md)

完成源码修改后，在仓库根目录运行 `node tests/qa/rail-submit/check.mjs`。脚本构建独立预览，并用 Chromium 检查英文、简体中文在桌面、320×568 手机及 320×568 下 200% 计算字号的表现。先安装锁定的工作区、游戏依赖及 Playwright Chromium；也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定本机 Chrome/Chromium 可执行文件。

此夹具加载真实游戏，通过游戏工具注册别名观察当前游戏状态并准备固定问题。键盘、指针、按钮、提交答案和游戏更新均使用生产实现。夹具可缩短当前问题或反馈的倒计时，检查正常阶段切换前后的按键是否被错误合并。测试覆盖方向上键/W 双击、长按重复、同键要求、触摸双击不得提交、选择答案后点击该答案卡片内部的“出发”、Enter/空格激活、暂停、下一题、布局及触摸目标。答案选择与“出发”使用互不嵌套的独立按钮。布局场景采用当前语言中题干和所有答案总字数最多的问题。失焦测试明确使用合成 blur 事件。受控浏览器时钟及手机视口模拟仅用于交互和布局回归，不能作为原生设备性能证据。

脚本启动临时 `127.0.0.1` 服务器，阻止外部请求，禁用 Toy，并在游戏加载前把存档映射到 `qa-rail-submit-v1:`。每个场景使用全新浏览器上下文，并验证未加前缀的哨兵值保持不变。含源码和构建哈希的报告与截图写入 `results/qa/rail-submit-<timestamp>/`。请勿部署此夹具，或将它混入生产 `src/dist/`。
